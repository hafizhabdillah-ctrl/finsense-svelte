🚀 FinSense Svelte Frontend

✅ Setup Complete!

Svelte frontend untuk FinSense telah berhasil disetup.

📦 Installation & Running

$ npm install $ npm run dev

Server akan berjalan di http://localhost:5173

⚙️ Configuration

Copy .env.example ke .env dan sesuaikan:

cp .env.example .env

Pastikan backend URL menunjuk ke server API Anda (default: http://localhost:3000/api)

  • ✅ Authentication (Login, Register, Password Reset)
  • ✅ Dashboard with Statistics
  • ✅ Stock Management

  • ✅ User Profile & Settings
  • ✅ Responsive Design

📁 Project Structure

  • src/pages/ - Route pages
  • src/lib/components/ - Reusable components
  • src/lib/services/ - API service layer
  • src/lib/stores/ - State management (Svelte Stores)
  • src/lib/utils/ - Utility functions

🔗 Key Routes

  • / - Landing page
  • /login - Login
  • /register - Register
  • /dashboard - Dashboard
  • /stocks - Stock Management
  • /transactions - Financial Records
  • /pos - POS Terminal
  • /debts - Debt Management
  • /logs - Inventory Logs

📚 Available Commands

  • npm run dev - Start development server
  • npm run build - Build for production
  • npm run preview - Preview production build
  • npm run lint - Run ESLint
